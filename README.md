# Aalok Singh Mehra - Portfolio

A professional developer portfolio showcasing my skills, experience, and projects as a Backend Software Developer.

## 🚀 Overview

This portfolio is built using **Next.js**, **React**, and **Tailwind CSS**. It features a modern, responsive design with smooth animations and a clean aesthetic.

## ✨ Features

- **Hero Section**: Introduction and social links.
- **Skills**: Technical expertise categorized by domain.
- **Experience**: Professional work history.
- **Projects**: Showcase of key projects with descriptions and links.
- **Education & Certifications**: Academic background and professional certifications.
- **Responsive Design**: Optimized for all screen sizes.
- **Dark Mode Support**: Built-in support for theme switching.

## 🛠️ Tech Stack

- **Framework**: [Next.js](https://nextjs.org/) (App Router)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **UI Components**: [Radix UI](https://www.radix-ui.com/), [Shadcn UI](https://ui.shadcn.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/) (or custom CSS/Tailwind animations)
- **Language**: [TypeScript](https://www.typescriptlang.org/)

## 🏁 Getting Started

### Prerequisites

- Node.js (v18 or higher)
- pnpm (recommended) or npm/yarn

### Installation

1. Clone the repository:
   ```bash
   git clone <repository-url>
   ```

2. Install dependencies:
   ```bash
   pnpm install
   ```

### Development

Start the development server:
```bash
pnpm dev
```

The application will be available at `http://localhost:3000`.

### Building for Production

```bash
pnpm build
pnpm start
```
